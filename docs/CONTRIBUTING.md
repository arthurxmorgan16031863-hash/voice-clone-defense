# Contributing to Voice Clone Defense

Thank you for contributing to the Voice Clone Defense project.

This document defines the team's GitHub workflow for contributing code, documentation, testing, security improvements, and other project changes.

## 1. Create a Branch

Do not make development changes directly on `main`.

Create a separate branch from the latest `main` branch.

Recommended branch naming:

- `feature/<short-description>`
- `fix/<short-description>`
- `docs/<short-description>`
- `test/<short-description>`
- `security/<short-description>`
- `refactor/<short-description>`

Examples:

```text
feature/audio-analysis
fix/file-validation
docs/api-documentation
test/risk-engine
security/upload-validation
refactor/frontend-components
